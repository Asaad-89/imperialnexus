# Imperial Nexus — imperialnexu.com

موقع شركة Imperial Nexus لحلول الاتصالات وتقنية المعلومات في الرياض.

## الملفات
- `index.html`: الموقع كاملاً (الصفحات والتنسيق والبرمجة).
- `imperial-theme.js`: طبقة الألوان والثيم.

## النشر
الموقع مستضاف على Hostinger. أي تعديل يُدمج في فرع `main` يُنشر على الموقع.

## طريقة العمل
1. كل تعديل يتم في فرع مستقل ويُفتح له Pull Request.
2. تتم مراجعة التعديل والموافقة عليه قبل الدمج في `main`.
3. لا تُرفع أي مفاتيح أو كلمات مرور إلى هذا المستودع لأنه عام.

النسخة القديمة من القالب محفوظة في فرع `legacy-template`.
