# 🌤️ لوحة معلومات الطقس الذكية - Smart Weather Dashboard

## نبذة عن المشروع

**Weather Dashboard** هو تطبيق ويب متقدم لعرض بيانات الطقس في الوقت الفعلي من أي مكان في العالم. يوفر واجهة احترافية وسهلة الاستخدام مع دعم كامل للغة العربية.

## الميزات الرئيسية

### 🌍 البحث والموقع
- 🔍 بحث متقدم عن المدن مع اقتراحات تلقائية
- 📍 تحديد الموقع الحالي تلقائياً (GPS)
- ❤️ حفظ المدن المفضلة للوصول السريع

### 🌡️ معلومات الطقس
- 🌡️ درجة الحرارة الحالية والشعورية
- 💧 معدل الرطوبة والضغط الجوي
- 💨 سرعة الريح والرؤية الأفقية
- ☀️ فهرس الأشعة فوق البنفسجية
- 🌅 وقت الشروق والغروب
- 🌧️ احتمالية الأمطار وكميتها

### 📊 التوقعات
- ⏰ توقعات بالساعة (8 ساعات القادمة)
- 📅 توقعات 5 أيام مفصلة
- 📈 رسوم بيانية للتغيرات المتوقعة

### ⚙️ الإعدادات
- 🌡️ اختيار وحدة قياس درجة الحرارة (مئوية/فهرنهايت)
- 🌙 نمط المظهر (داكن/فاتح/تلقائي)
- 🗣️ دعم متعدد اللغات (العربية/الإنجليزية)
- 💾 حفظ التفضيلات محلياً

## كيفية الاستخدام

### 1. الإعداد الأولي

#### احصل على مفتاح API
1. توجه إلى [OpenWeatherMap](https://openweathermap.org/api)
2. أنشئ حساباً مجانياً
3. انسخ مفتاح API الخاص بك

#### أضف المفتاح في التطبيق
افتح `script.js` وأضف مفتاحك:

```javascript
const API_KEY = 'YOUR_API_KEY_HERE';
```

### 2. تشغيل التطبيق

#### الطريقة الأولى: فتح مباشر
```bash
افتح ملف index.html في متصفحك
```

#### الطريقة الثانية: خادم محلي

**Python:**
```bash
python -m http.server 8000
# ثم اذهب إلى http://localhost:8000/weather-dashboard
```

**Node.js (http-server):**
```bash
npm install -g http-server
http-server weather-dashboard -p 8000
```

**Live Server (VS Code):**
- ثبت extension "Live Server"
- اضغط كليك يمين على `index.html`
- اختر "Open with Live Server"

### 3. الاستخدام الأساسي

#### البحث عن مدينة
1. أدخل اسم المدينة في حقل البحث
2. اختر من الاقتراحات أو اضغط بحث
3. سيتم عرض الطقس الحالي والتوقعات

#### استخدام الموقع الحالي
1. اضغط زر "الموقع الحالي"
2. وافق على طلب الوصول إلى الموقع
3. سيتم جلب بيانات الطقس تلقائياً

#### إضافة مدينة للمفضلة
1. ابحث عن المدينة المطلوبة
2. اضغط أيقونة القلب في بطاقة الطقس
3. ستظهر في قائمة المفضلة

#### عرض المدن المفضلة
1. اضغط زر "المفضلة"
2. اختر مدينة من القائمة
3. سيتم عرض طقسها مباشرة

## البيانات المخزنة محلياً

التطبيق يحفظ البيانات التالية في `localStorage`:

```javascript
// وحدة قياس درجة الحرارة
localStorage.setItem('tempUnit', 'metric' | 'imperial');

// نمط المظهر
localStorage.setItem('theme', 'dark' | 'light' | 'auto');

// المدن المفضلة
localStorage.setItem('favorites', JSON.stringify([
    { name: 'الرياض', lat: 24.7136, lon: 46.6753 },
    // ...
]));
```
